# Koroot (كروت)
Digital loyalty cards for cafes. Customer joins with a phone number and gets a QR stamp card; the cashier stamps it; free reward after N visits; the owner sees customers who stopped coming and messages them on WhatsApp.
Run: `npm i && node server.js` (PORT, DB env vars). Sample data: `node seed.js` (cafe qahwet-elrokn, PIN 1234).
Free tools only: Node, a JSON file, no paid services. Built by Eng Angelo Rezq.
