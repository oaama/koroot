# Koroot WhatsApp bridge
Unofficial WhatsApp Web session (Baileys). Hosted on an always-on Node host (Botkeep free server).
Env: KOROOT_URL (e.g. https://koroot.angluosr.workers.dev), BRIDGE_SECRET (same value as the worker secret), MAX_SESSIONS (default 3).
Start command: `npm start`. Sessions are stored in the Koroot worker, not on disk.
Each cafe links its number from its admin page (scan the QR in WhatsApp > Linked devices).
